# Maintaining this profile

This repository is the source of the README shown on [github.com/yanmingyu92](https://github.com/yanmingyu92). The images are static SVGs generated by small Python scripts. Nothing depends on a third-party rendering service, except the skill-icons and shields.io badges.

## Layout

| Path | Purpose |
|---|---|
| `README.md` | The profile page |
| `neofetch.json` | Text on the terminal-style card |
| `assets/portrait.jpg` | Source photo for the ASCII portrait |
| `scripts/generate_card.py` | Card SVGs (dark/light) with live GitHub stats |
| `scripts/generate_banner.py` | Hero banner and footer wave |
| `scripts/generate_impact.py` | "By the numbers" tiles (edit `TILES`) |
| `scripts/update_feed.py` | Latest articles from the jaimeyan.com RSS feed (between `FEED` markers) |
| `tests/` | pytest unit tests (no network) |
| `.github/workflows/neofetch.yml` | Weekly refresh of card stats and latest writing |
| `.github/workflows/snake.yml` | Optional contribution-snake animation (disabled) |

## Regenerate locally

Requires Python 3.10+ with Pillow; pytest is needed only for the tests.

```bash
pip install "pillow>=11,<13" pytest
python -m pytest -q tests
GITHUB_TOKEN=$(gh auth token) python scripts/generate_card.py --require-stats
python scripts/generate_banner.py
python scripts/generate_impact.py
python scripts/update_feed.py
```

Run `generate_card.py` with `--offline` to render without stats. A personal token counts private contributions too; the Actions token counts public contributions only.

## Automation

`neofetch.yml` runs:
- every Monday;
- on demand;
- on pushes that touch the config, the assets or the scripts.

It refuses to commit a card with missing stats. A failure to read the RSS feed does not block the card refresh.
